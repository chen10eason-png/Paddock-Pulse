# Paddock Pulse v1.4.0

非官方 F1 iPhone/iPad PWA，保留 v1.3.0 全部首頁、收藏、車手/車隊詳情與積分榜。

## 新增：分站比賽結果
- 新增「賽果」分頁，選擇 2026 年任意一站。
- 每場實際有舉行的 FP1/FP2/FP3、衝刺排位、衝刺賽、排位賽和正賽獨立切換。
- 車手完整排名、車隊、場次時間或差距；前三名展示卡片。
- 賽程展開後「查看本站賽果」可直達。
- 未舉辦、尚未完成或來源尚未公布的成績不會捏造。
- Jolpica-F1 標準 API 提供正賽、衝刺賽與排位賽（若可取得），OpenF1 的歷史場次結果補足 FP1/FP2/FP3、衝刺排位，以及標準 API 缺漏。
- 依需求才查詢個別場次、單場結果快取 6 小時，避免一次大量打 API。
- 保留原本 localStorage 車手與車隊收藏，不需重選。

## 使用
下載 ZIP 解壓縮，把 `paddock-pulse-v1.4.0` 裡的檔案 **全部** 上傳到 GitHub Pages repo 根目錄。HTTPS、localhost 可用；直接用 `file://` 開啟將受跨來源限制。網頁右上角 ↻ 更新基礎賽程與積分，賽果頁的 ↻ 更新目前選取的場次。

## 資料來源與限制
- Jolpica-F1：https://api.jolpi.ca/docs/
- OpenF1：https://openf1.org/docs/
- 練習/衝刺排位的 OpenF1 結果在官方公布後通常才會出現，來源缺資料時保留等待狀態。真正即時 OpenF1 資料需要額外授權，此版本僅做賽後結果。
- 這是瀏覽器直連公開端點，若對方遇到跨來源或流量限制，App 會提示重試；不會假裝有結果。
- 本版不包含實體照片/車隊徽章授權、原生 iOS Widget 或 Live Activities。
